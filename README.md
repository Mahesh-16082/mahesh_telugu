# Shorts Platform

A new news platform with a public Shorts website and an admin portal.

## Technology Stack
- Frontend: React, TypeScript, Vite, pnpm, ESLint
- Backend: Python, FastAPI
- Database: PostgreSQL

## Project Structure
- frontend/ - Frontend application
- backend/ - Backend API
- docs/ - Project documentation

## Frontend Setup
cd frontend
pnpm install
pnpm dev
